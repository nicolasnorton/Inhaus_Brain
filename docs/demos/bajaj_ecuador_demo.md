# Bajaj Ecuador – Scooter Launch Demo

**Duration:** ~8 minutes  
**Client:** Bajaj Ecuador  
**Objective:** Scooter Launch Campaign targeting urban commuters

---

## Script

### 1. Launch (30s)
- Open Inhaus Brain dashboard
- Click **"Bajaj Ecuador – Scooter Launch"** demo button
- Demo mode activates with pre-loaded Bajaj knowledge base

### 2. Strategy Phase (2 min)
- AI Router classifies as a multi-step campaign
- Blackboard transitions: `idle → strategy → copywriting`
- Strategy Agent delivers competitor analysis (Honda, TVS)
- Market positioning and audience segmentation auto-generated

### 3. Creative Assets (2 min)
- Copywriter generates taglines in Spanish + English
- Trigger Imagen 3 for scooter lifestyle visuals
- Show GenUI: budget_chart showing media spend allocation
- Kanban board auto-populated with deliverables

### 4. Media Plan (1.5 min)
- Media Buyer Agent produces placement recommendations
- Social platform breakdown (Instagram, TikTok, Meta)
- Budget allocation visualization via GenUI

### 5. Proposal & Export (1.5 min)
- Full proposal generation with pricing tiers
- One-click PDF export
- Show the proposal detail screen with edit capabilities

### 6. Approval & Wrap (30s)
- Approve the campaign
- Watch all 6 Blackboard phases complete
- Confirm `full_workflow_complete` analytics event
