# Nutrileche – Brand Refresh Demo

**Duration:** ~8 minutes  
**Client:** Nutrileche  
**Objective:** Full brand refresh campaign — new identity, digital-first strategy

---

## Script

### 1. Launch (30s)
- Open Inhaus Brain dashboard
- Click **"Nutrileche – Brand Refresh"** demo button
- Note: This is the newest demo, mirroring Bajaj's full depth

### 2. Strategy Phase (2 min)
- Brief: "Nutrileche needs a modern brand refresh targeting health-conscious millennials"
- Router → Strategy Agent activates
- Watch the Blackboard show real-time phase transitions
- Strategy output: brand positioning, competitive landscape, audience personas

### 3. Creative Generation (2 min)
- Copywriter generates brand messaging pillars
- Imagen 3 produces packaging concept visuals
- Veo generates a 15-second product hero video
- All assets appear in the Creative Studio

### 4. Proposal Assembly (2 min)
- Navigate to the Proposal Specialist
- AI assembles deliverables, timeline, and pricing
- Show the active quote bar with margin calculations
- PDF export with comprehensive branding proposal

### 5. Approval & Publishing (1 min)
- Click "Approve" — Blackboard → `approved`
- Show publish dashboard with deployment options
- Demonstrate the full analytics trail in debug panel

### 6. Analytics Verification (30s)
- Open Firebase console (or debug overlay)
- Show events: `campaign_started → phase_completed (1-6) → proposal_generated → human_approval → full_workflow_complete`
- All events contain `client: nutrileche`, `app_mode: v1_demo`
