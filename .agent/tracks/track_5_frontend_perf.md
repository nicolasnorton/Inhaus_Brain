# Track 5: Frontend Perf Optimizer Agent

## Mission
Optimize the frontend for performance and responsiveness.

## Key Objectives
1.  **State Management**: Optimize Riverpod selectors to prevent unnecessary rebuilds.
2.  **Code Splitting**: Split the `Creative Studio` and `ADK` features into lazy-loaded modules.
3.  **Media Handling**: Implement lazy loading for media thumbnails and efficient caching.
4.  **Local Cache**: Use IndexedDB or local storage to cache Blackboard state on the web, reducing network calls.

## Deliverables
*   Optimized Widget trees.
*   Lazy-loaded routes configuration.
*   Caching layer implementation.
