# Client User Role
## Description
**Role Name:** Client User (ClientUser)
**Scope:** External / Limited Access
**Purpose:** Grants read-only access to specific reports, dashboards, and assets generated for the client's organization. This role prevents access to other clients' data or internal agency tools.

---

## Descripción
**Nombre del Rol:** Usuario Cliente (ClientUser)
**Alcance:** Externo / Acceso Limitado
**Propósito:** Otorga acceso de solo lectura a informes, tableros y activos específicos generados para la organización del cliente. Este rol impide el acceso a datos de otros clientes o herramientas internas de la agencia.
