# Client User Role

## English
The Client User role is tailored for external clients who need to monitor their project progress and review deliverables. This is a restricted role focused on transparency and feedback.
- **Access Level**: Restricted read-only / feedback access.
- **Permissions**: View own Reports, View own Dashboards, View own Campaigns, Provide Feedback.
- **Constraints**: Cannot access other clients' data or agency-internal tools.

---

## Español
El rol de Usuario Cliente está diseñado para clientes externos que necesitan monitorear el progreso de sus proyectos y revisar entregables. Este es un rol restringido enfocado en la transparencia y retroalimentación.
- **Nivel de Acceso**: Acceso restringido de solo lectura / retroalimentación.
- **Permisos**: Ver sus propios Reportes, Ver sus propios Dashboards, Ver sus propias Campañas, Proveer Retroalimentación.
- **Restricciones**: No puede acceder a datos de otros clientes ni a herramientas internas de la agencia.
