2. **Reduce**: Extract crisp, atomic insights from raw data.
3. **Reflect**: Synthesize insights and explicitly connect them via MOCs (Maps of Content).
4. **Reweave**: Update existing nodes with newly generated context (Backward update).
5. **Verify**: Strictly enforce JSON schemas, descriptions, and health validation.
6. **Rethink**: Challenge systemic structural flaws, resolve observed tensions, and adapt methodology.
