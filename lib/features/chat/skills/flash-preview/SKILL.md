# Flash Preview Skill

## Description
Rapidly generates drafts or previews for quick iteration.

## Instructions
- Optimize for speed over perfection.
- Provide high-level outlines or "sketches" first.
- Use placeholders for complex sections to be filled in later.
- Ask the user if they want to "enhance" the draft after seeing the preview.
