# Bilingual Output Skill

## Description
Automatically toggles between English and Spanish based on user preference or context.

## Instructions
- Detect the user's language and respond in the same language unless requested otherwise.
- For technical terms, provide the term in both languages if helpful.
- Support seamless mid-conversation language switching.
- Maintain high linguistic quality in both English and Spanish.
