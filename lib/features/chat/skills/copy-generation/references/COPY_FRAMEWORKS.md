# Copywriting Frameworks Reference

## AIDA (Awareness Campaigns)
- **A**ttention: Hook that stops the scroll. Unexpected stat, bold claim, or relatable pain.
- **I**nterest: Expand on the hook. Why should they keep reading?
- **D**esire: Paint the outcome. Show the transformation, not the product.
- **A**ction: One clear CTA. No "Learn more AND Sign up."

## PAS (Consideration / Retargeting)
- **P**roblem: Name the pain precisely. Specificity = credibility.
- **A**gitation: Amplify the cost of inaction. What happens if they don't act?
- **S**olution: Position the offer as the inevitable answer.

## FAB (Conversion / Bottom Funnel)
- **F**eature: What it is.
- **A**dvantage: What it does better than the alternative.
- **B**enefit: What the customer gains / feels.

## Power Words by Objective

| Objective | Power Words |
| :--- | :--- |
| Urgency | Hoy, Ahora, Últimas horas / Today, Now, Limited time |
| Trust | Garantizado, Comprobado / Guaranteed, Proven |
| Exclusivity | Solo para ti, Acceso exclusivo / Members only, Exclusive |
| Value | Gratis, Sin costo / Free, No cost |

## Ad Policy Risk Flags

- `#1`, `best`, `guaranteed results` → Requires substantiation.
- `lose weight`, `cure`, `treat` → Health claims; may require medical disclaimer.
- `before/after` imagery references in copy → Restricted on Meta.
- `limited time` without real deadline → Deceptive; avoid.
